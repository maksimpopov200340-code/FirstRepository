# **Real-Time-Capable Modeling of ICRF Heating on NSTX and WEST via Machine Learning Approaches**

## **Abstract** 

A real-time capable core Ion Cyclotron Range of Frequencies  heating model is developed. This  model is trained on TORIC ICRF spectrum solver simulations of the expected flat-top operation scenarios in NSTX and WEST assuming Maxwellian plasmas. This model can be implemented into integrated modeling frameworks for real-time control application.

## **Conclusions**

Main quantitative results:
- The achived prediction time varies from 2 to 50 $\mu s$. It's much faster compared to TORIC(1-5 min)
- Coefficient of determination of NSTX HHFW power deposition equals 0,94-0,97. $R^2_{e} = 0.97$; $R^2_{D} = 0.94$.
- Coefficient of determination of Minority Heating scenario on WEST equals $R^2_{e} = 0.81$; $R^2_{D} = 0.70$.

It can be concluded, that TORIC-ML model has great calculation speed and efficancy. But in complicated scenarious, such as minority heating on WEST, this model doesn't have enough accuracy for real-time control application.
